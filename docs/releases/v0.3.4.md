# Microsoft Widgets 0.3.4

## Security and Reliability

- Pair each Planner and Outlook widget with the helper after upgrading. Open setup from the helper icon or Start menu and approve only the matching code shown on your display.
- Planner pairing requests and connected widgets appear in Planner; Outlook requests and widgets appear in Outlook. The Overview shows each integration's pending count separately.
- Upgrades from earlier installed helpers now stop the known legacy versions before replacing files; no manual tray quit is needed for those releases.
- Helper setup and management now require the local owner session. Planner data and calendar responses are isolated across sign-out, account changes, and permission loss.
- Installer and package creation use verified release contents and checksums. The installer remains unsigned; follow your organization's installation policy.

## Planner Edge 0.3.1

- Add and organize tasks with persistent filters, My tasks, checklist editing, labels, priority, dates, bucket, and assignees.
- Read and explicitly save notes, and view or post task chat when the organization grants its optional permission.
- Restore the last board view immediately while fresh data loads. Re-import the widget in iCUE for this version.

## Outlook Edge 0.2.1

- Restore the cached calendar immediately while live data refreshes.
- Keep event dialogs and calendar data aligned with the current authorization and selected sources.
- Re-import the widget in iCUE for this version.

## Updating

Install Microsoft Widgets Helper 0.1.5 with **Check for updates** or the 0.3.4 installer, then re-import both widget packages in iCUE. Saved account and widget settings are retained, but each widget must be paired once with the updated helper. Outlook remains read-only.
