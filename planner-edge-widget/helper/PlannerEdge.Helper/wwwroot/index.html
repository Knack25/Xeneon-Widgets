Planner Edge

Connect your work account and choose the Planner board shown on your XENEON EDGE.

1. Connect Microsoft Planner

Paste the ID from your organization's Microsoft Entra app registration. This is not a password or client secret.

Where do I find these IDs?

In the Microsoft Entra admin center, open App registrations and select your public client app. Copy its Application (client) ID from Overview. You may also copy the Directory (tenant) ID. The app needs delegated Microsoft Graph permissions User.Read and Tasks.ReadWrite, plus a mobile/desktop redirect URI of http://localhost. Your IT administrator may need to create or approve it.

2. Sign in
Checking account...

Showing assignee names requires User.ReadBasic.All. Editing assignees requires GroupMember.ReadBasic.All. Your work administrator may need to approve these permissions.

Microsoft sign-in shows an error?

If you see AADSTS900971: No reply address provided, the Microsoft app registration needs a redirect address:

  1. Open the app registration in Microsoft Entra.
  2. Open Authentication, then add the Mobile and desktop applications platform.
  3. Add the redirect URI http://localhost and save.
  4. Return here and try signing in again.

If you cannot edit the app registration, send those steps to your IT administrator.
