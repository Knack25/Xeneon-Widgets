# Microsoft Widgets 0.3.0

## Install

Download **MicrosoftWidgetsSetup-0.3.0.exe** below and run it. This per-user Windows installer bundles Planner Edge 0.3.0 and Microsoft Widgets Helper 0.1.1; no PowerShell or separate .NET installation is needed.

Open **Microsoft Widgets Setup** from the Start menu, connect your work account, choose a board, and download the bundled widget from the setup page. Import it in iCUE through **XENEON EDGE > Widgets > +**. iCUE still requires this manual import step.

The installer offers optional startup at Windows sign-in and a desktop shortcut. A Stop Helper shortcut and standard Windows uninstall entry are included. Existing account and board settings are preserved. Close older portable helper versions before installing.

## Included

- Shared Microsoft Widgets Helper, ready to host additional Microsoft integrations.
- Board switching, My tasks filter, and new-task creation.
- Task details with checklist editing, multiple assignees, bucket changes, due-date calendar, and notes.
- Corrected bucket, task, and checklist ordering; sticky bucket headings and scroll-position preservation.
- Guided setup with bundled widget download, board preview, and helper version/status controls.

## Requirements and Notes

- Windows 10 22H2 or later, x64-compatible system, iCUE, and XENEON EDGE.
- A Microsoft work account with Planner access and an Entra app registration. Your administrator may need to approve delegated permissions; installation cannot bypass organization policy.
- The installer is unsigned and Windows may report an unknown publisher. Follow your organization's software policy.
- Uninstall preserves local account/settings data. Sign out in setup before uninstalling to clear the account cache.

The portable helper ZIP and standalone `.icuewidget` are alternative downloads; most users only need the installer. `INSTALL.md` contains the full guide and `SHA256SUMS.txt` provides artifact checksums.
