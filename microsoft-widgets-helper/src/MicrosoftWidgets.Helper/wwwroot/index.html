Application configuration

Paste the ID from your organization's Microsoft Entra app registration. This is not a password or client secret.

Where do I find these IDs?

In the Microsoft Entra admin center, open App registrations and select your public client app. Copy its Application (client) ID from Overview. You may also copy the Directory (tenant) ID. Configure a mobile/desktop redirect URI of http://localhost. Planner uses User.Read and Tasks.ReadWrite; Outlook's complete permission list is below. Your IT administrator may need to create or approve the registration.

Planner

Connection

Permissions

Planner uses the delegated Microsoft Graph permissions User.Read and Tasks.ReadWrite. Task chat additionally requires Group-Conversation.ReadWrite.All to read and post Planner comments; existing users may need to select Enable task chat once. Without that consent, only task chat is unavailable, and notes continue to work through Tasks.ReadWrite. The optional User.ReadBasic.All permission shows assignee names, and GroupMember.ReadBasic.All enables assignee editing. Your work administrator may need to approve these permissions.

Microsoft sign-in shows an error?

If you see AADSTS900971: No reply address provided, the Microsoft app registration needs a redirect address:

  1. Open the app registration in Microsoft Entra.
  2. Open Authentication, then add the Mobile and desktop applications platform.
  3. Add the redirect URI http://localhost and save.
  4. Return here and try signing in again.

If you cannot edit the app registration, send those steps to your IT administrator.

Outlook permissions for your administrator

Register these delegated Microsoft Graph permissions together on the same app: User.Read, Calendars.Read.Shared, MailboxSettings.Read, and Group.Read.All. Connect Outlook requests the complete bundle in one sign-in flow.

Group.Read.All requires administrator consent and permits reading other accessible group content, including conversations and files. This widget only uses the membership and calendar APIs. No calendar write or mail permissions are requested.

After your administrator approves the complete bundle, select Connect Outlook again. This uses your existing account and does not require consenting to Planner first.
