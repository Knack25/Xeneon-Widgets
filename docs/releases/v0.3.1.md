# Microsoft Widgets 0.3.1

- Microsoft Widgets Helper 0.1.2 checks for stable updates at startup and daily.
- **Check for updates** in setup checks immediately.
- **Update now** asks for approval of the offered version before downloading, verifying, and installing. The helper restarts and keeps account settings and installer preferences.
- Failed checks/downloads are retryable and do not interrupt Planner. Downloads use the repository's GitHub release assets and GitHub-provided SHA256 digests.
- Planner Edge remains at 0.3.0. This release does not require a new widget import.

Existing 0.3.0 users need one manual installer upgrade to get in-app updates. Portable builds can check but must use the installer to enable in-app installation. The installer remains unsigned; follow your organization's installation policy.
