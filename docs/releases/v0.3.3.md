# Microsoft Widgets 0.3.3

## Outlook Edge 0.2.0

- Choose Light, Dark, or System in Calendar settings under Appearance.
- Light is the default. Each widget saves its own appearance choice.
- System follows device theme changes automatically.
- Dark mode preserves calendar colors and improves event text contrast.
- Theme changes do not reload calendar data.

## Documentation

- README gallery includes Outlook light/dark views, event details, Planner board/task details, and helper Overview.
- All screenshots use fictional demo data.

## Updating

Update Microsoft Widgets Helper to 0.1.4 using **Check for updates**, then download and re-import Outlook Edge 0.2.0 in iCUE to receive the appearance controls. Existing settings are retained. Planner remains at 0.3.0 and does not need re-importing. The Windows installer remains unsigned.
