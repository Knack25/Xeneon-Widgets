# Microsoft Widgets 0.3.2

- Microsoft Widgets Helper 0.1.3 adds a Windows notification-area icon with a version tooltip.
- A modular W logo with a purple accent identifies the helper and installer. The tray uses a light or dark foreground to match the Windows taskbar theme.
- Left-click opens the helper setup webpage.
- Right-click offers **Open setup**, **Check for updates**, and **Quit helper**.
- Checking from the tray opens the Updates section and checks immediately. Installing still requires approval.
- The tray icon closes with the helper and returns after restart, including update restarts. Windows may place it under the hidden-icons arrow.

## Outlook Edge 0.1.0

- Read-only Week, Month, and Agenda views, with Week as the default.
- Select multiple personal, shared/delegated, and Microsoft 365 group calendars, subject to account access and Graph permissions.
- Calendar colors, working hours, configurable weekends, first day of week, and time zone.
- Event details include attendees, organizer, location, description, and meeting launch on the helper PC.
- Each native widget pairs with the helper and keeps its own display preferences.
- XML-compatible widget packaging fixes iCUE's misleading "Missing title element" import error.

## Helper Setup

- Overview, Planner, Outlook, and Settings navigation replaces the long setup page.
- Existing permissions are detected silently; enabled actions are disabled and boards/calendars load automatically.
- Connection failures offer retry without forcing consent. Missing permissions still require an explicit user action.
- Technical configuration and installation instructions are expandable. New installations open account configuration directly.

## Installation

Planner Edge remains at 0.3.0; existing Planner installations do not require a new import. Import the bundled Outlook widget to add calendars. Outlook needs its own delegated permission bundle; see `OUTLOOK.md` for administrator setup. The installer includes the Windows desktop runtime. Existing 0.3.1 users can use **Check for updates** and **Update now** once this release is published. Earlier users need the installer download. The installer remains unsigned.

Modal isolation no longer toggles the calendar's inert state; the overlay, keyboard focus trap, and accessibility boundary remain in place.
