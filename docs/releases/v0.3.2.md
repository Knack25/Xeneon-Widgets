# Microsoft Widgets 0.3.2

- Microsoft Widgets Helper 0.1.3 adds a Windows notification-area icon with a version tooltip.
- Left-click opens the helper setup webpage.
- Right-click offers **Open setup**, **Check for updates**, and **Quit helper**.
- Checking from the tray opens the Updates section and checks immediately. Installing still requires approval.
- The tray icon closes with the helper and returns after restart, including update restarts. Windows may place it under the hidden-icons arrow.

Planner Edge remains at 0.3.0; no new widget import is required. The installer includes the Windows desktop runtime. Existing 0.3.1 users can use **Check for updates** and **Update now** once this release is published. Earlier users need the installer download. The installer remains unsigned.
